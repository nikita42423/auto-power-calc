Определение необходимой силы тока для устройств автомобиля.
Услуги - устройсва (колонки, компьютер, внешние устройства по USB), их мощность (Вт) и сопротивление (Ом).
Заявка - расчет минимальной силы тока (А), которую должен выдавать автомобиль для каждого из устройств.


Решение. Сила тока, необходимая для работы устройства, определяется на основе его электрических характеристик. Для расчёта минимального значения силы тока (I) используем закон Ома для участка цепи: I = U / R, где U — напряжение бортовой сети автомобиля (стандартно 12 В), а R — сопротивление устройства. Поскольку в исходных данных указана мощность (P) и сопротивление (R), силу тока также можно вычислить через мощность: I = √(P / R) (из формулы P = I² * R). При этом для каждого устройства сопротивление R можно не искать в таблицах, а просто рассчитать самостоятельно исходя из номинальной мощности и напряжения бортовой сети (12В) по формуле R = U² / P = 144 / P.

Для каждого устройства (услуги) необходимо хранить его мощность и сопротивление, чтобы вычислить требуемый ток.
В заявке пользователь выбирает набор устройств, а в результате (м-м) фиксируется расчётное значение минимальной силы тока для каждого из них.

Поля в таблицах по вашей теме (помимо обязательных полей):

Таблица «Услуги»:
Название устройства — строка
Мощность устройства (Вт) — число
Сопротивление устройства (Ом) — число
Статус — строка (черновик, опубликован, удален)

Таблица «Заявка»:
Напряжение бортовой сети (В) — число (по умолчанию 12)

Таблица «м-м» (результат):
Числовое поле «Минимальная сила тока (А)» — заполняется автоматически при изменении статуса заявки на «Расчёт завершён» (вычисляется по формуле I = √(P / R) для каждого устройства)
