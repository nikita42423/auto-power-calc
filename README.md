# Автомобильный калькулятор тока

Определение необходимой силы тока для устройств автомобиля.

## Ветви

| Ветвь | Описание |
|-------|----------|
| `main` | Текущая ветвь — описание проекта |
| `lab1` | Лабораторная работа 1 |
| `lab2` | Лабораторная работа 2 (в разработке) |

## Лабораторная работа 1

Веб-приложение на FastAPI для расчёта минимальной силы тока автомобильных устройств.

**Функциональность:**
- Просмотр устройств в виде сетки (grid) и карточки (feed)
- Добавление и редактирование устройств
- Фильтрация по мощности

**Стек:** FastAPI, Jinja2, MinIO (Docker)

**Формулы:**
- `I = U / R` (закон Ома, U = 12В)
- `I = √(P / R)` (через мощность)
